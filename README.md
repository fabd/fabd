# Hi, I'm Fabrice

I build tools for things I'm passionate about — Japanese language learning and gaming.

### [Kanji Koohii](https://github.com/fabd/kanji-koohii)
A web app to help Japanese learners remember how to write the kanji using Spaced Repetition and the Heisig method.
`PHP / TypeScript / Vue` · ★ 247

### [Runewizard for Diablo II](https://github.com/fabd/diablo2-runewizard)
Check out what Runewords you can make in **Diablo II Resurrected** with the runes you have found.
`TypeScript / Vue` · ★ 46

### [Skyrim Mods](https://github.com/fabd/skyrimui) *(archived)*
Better Dialogue Controls & Better MessageBox Controls — two highly popular mods I created for Skyrim, 1.6million downloads on NexusMods.
`ActionScript`

### [Dr. Mario](https://github.com/fabd/drmario) *(archived)*
A faithful NES Dr. Mario re-creation. One of my earliest game programming projects (~1998).
`C++`
